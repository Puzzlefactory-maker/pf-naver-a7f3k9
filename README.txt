=====================================================================
 네이버 화면 - 안드로이드 앱 설치용 배포 파일
=====================================================================

[ 폴더에 들어있는 파일 ]
  index.html              화면 본체 (PC/모바일 자동 전환)
  manifest.webmanifest    앱 이름·아이콘·실행 방식 정보
  sw.js                   오프라인 실행 + 자동 업데이트 담당
  icon-192.png            앱 아이콘 (작은 크기)
  icon-512.png            앱 아이콘 (큰 크기)
  icon-maskable-512.png   안드로이드 원형/각진 아이콘용
  seed.js                 (선택) 관리자모드에서 만든 데이터 파일
  README.txt              이 문서

---------------------------------------------------------------------
1. GitHub 에 올리기
---------------------------------------------------------------------
 1) github.com 에서 새 저장소(Repository)를 만듭니다. Public 으로 만드세요.
 2) 저장소 화면에서 Add file > Upload files 를 누르고
    이 폴더의 파일을 전부 끌어다 놓은 뒤 Commit changes 를 누릅니다.
    (폴더째로 올리지 말고 '파일들'을 올려야 합니다)
 3) Settings > Pages 로 들어가서
      Source : Deploy from a branch
      Branch : main / (root)
    으로 두고 Save 를 누릅니다.
 4) 1~2분 뒤 주소가 나옵니다.
      https://내아이디.github.io/저장소이름/

---------------------------------------------------------------------
2. 안드로이드 폰에 앱으로 설치하기
---------------------------------------------------------------------
 1) 폰의 크롬(Chrome)으로 위 주소에 접속합니다.
 2) 우측 상단 점 3개(⋮) 메뉴 > "앱 설치" 또는 "홈 화면에 추가" 를 누릅니다.
    (화면 아래에 설치 안내 배너가 뜨기도 합니다)
 3) 홈 화면에 초록색 N 아이콘이 생깁니다.
    아이콘으로 실행하면 주소창 없이 앱처럼 전체화면으로 열립니다.
 * 반드시 https:// 주소로 접속해야 설치 메뉴가 나옵니다.
 * 삼성 인터넷 브라우저는 메뉴 > "현재 페이지 추가" > "홈 화면" 입니다.
 * 아이폰(사파리)은 공유 버튼 > "홈 화면에 추가" 입니다.

---------------------------------------------------------------------
3. 수정 내용 반영하기 (업데이트)
---------------------------------------------------------------------
 - index.html 을 고쳐서 GitHub 에 같은 이름으로 다시 올리면 끝입니다.
   설치된 앱을 다시 실행하면 자동으로 최신 버전이 됩니다.
   (앱을 지우고 다시 설치할 필요 없습니다)
 - 접속자에게 "0월 0일 업데이트 버전입니다" 팝업을 1회 띄우려면
   index.html 안의 아래 줄에서 날짜만 바꾸세요.
       const APP_VERSION = '2026-09-29';
 - 아이콘이나 manifest 까지 새로 받게 하려면
   sw.js 의 첫 줄 CACHE 날짜도 함께 바꿉니다.
       const CACHE = 'naver-mock-2026-09-29';

---------------------------------------------------------------------
4. 내용(계정·메일) 배포하기
---------------------------------------------------------------------
 - 관리자모드에서 "배포용 데이터 파일 만들기(seed.js)" 를 누르면
   seed.js 가 내려받아집니다. 이 파일을 index.html 과 같은 위치에 올리면
   접속하는 모든 기기에 같은 계정·메일 내용이 표시됩니다.
 - seed.js 가 없어도 앱은 정상 동작합니다(그 기기에 저장된 내용만 사용).

---------------------------------------------------------------------
5. 관리자모드
---------------------------------------------------------------------
 - PC  : 우측 하단 톱니 버튼을 5초간 누르고 있기
 - 모바일 : 메뉴 화면 또는 메일 서랍의 톱니 아이콘을 5초간 누르고 있기
 - 나가기 : "손님모드로 보기" 버튼 (이 버튼을 눌러야 다시 잠깁니다)

---------------------------------------------------------------------
6. 알아두기
---------------------------------------------------------------------
 - GitHub Pages 주소는 공개 주소입니다. 링크를 아는 사람은 접속할 수 있습니다.
 - 관리자모드에서 입력한 내용은 그 기기의 브라우저에 저장됩니다.
   여러 기기에 같은 내용을 넣으려면 위 4번(seed.js)을 이용하세요.
 - 인터넷이 끊겨도 한 번 연 적이 있는 기기에서는 앱이 실행됩니다.
